# 碎裂档案浮动应用设计

**日期**：2026-08-26  
**状态**：已确认，待实施

## 目标

将现有 p5.js 碎裂互动作品加入桌宠 GitHub Pages，作为桌面上的一个“碎裂档案”图标。点击图标后，作品在现有可拖拽、可缩放、可关闭的浮动窗口中运行。

## 架构

主页保留现有的桌宠、妈妈的手与普通网页窗口功能。新增的碎裂作品使用 iframe 隔离，避免 p5.js 的全局函数、画布样式与主页脚本互相影响。

```text
桌宠主页 index.html
  └─ 碎裂档案图标
       └─ openFractureApp()
            └─ FloatWindow（应用模式）
                 └─ iframe: fracture/index.html
                      ├─ p5.js 2.3.1
                      ├─ sketch.js
                      └─ assets/IMG_2563.PNG、IMG_2565.PNG、IMG_2566.PNG
```

## 主页改动

- 在桌面左上角加入单个“碎裂档案”文件图标。
- 图标以 `IMG_2566.PNG` 的红眼作为缩略图，并标注“碎裂档案”。
- 点击图标调用 `openFractureApp()`，创建一个应用模式的 `FloatWindow`。
- 应用模式窗口标题为“碎裂档案”，隐藏普通网页窗口的网址输入区与“开”按钮，只保留标题与关闭按钮。
- 窗口仍沿用现有拖动、缩放、置顶与关闭实现。

## 作品页面

- 新增 `fracture/index.html`、`fracture/style.css`、`fracture/sketch.js`。
- 作品页从固定版本 p5.js 2.3.1 加载，不依赖 p5 Web Editor。
- 三张原始图片放在 `fracture/assets/`，页面使用相对路径加载。
- 使用已确认的碎裂交互：首次切成两片；之后点选碎片继续二分；依点击次数切换素材；包含边缘红白粒子、重叠泛光与文字效果。
- 页面加载素材期间显示简洁的加载状态；图片未就绪时不访问其尺寸，避免空白页或运行错误。
- 画布启用 `touch-action: none`，并保留 p5 的 `touchStarted`、`touchMoved`、`touchEnded` 入口；一次触摸只触发一次切割。

## 失败处理

- 作品素材加载失败：显示“素材加载失败，请刷新页面”，不继续绘制碎片。
- iframe 无法加载：浮动窗口保留关闭按钮，主页不会受到影响。
- 关闭窗口只销毁该窗口及其 iframe，宠物和其他窗口继续运行。

## 验收与验证

1. 首页出现“碎裂档案”图标，单击后只打开一个作品浮动窗口。
2. 浮动窗口可拖动、缩放、关闭；关闭后其余桌宠行为正常。
3. 作品显示初始图片，连续点击能切割指定碎片。
4. 桌面浏览器鼠标与 iOS 触屏都各自一次触发一次切割。
5. GitHub Pages 的相对路径能够加载 p5.js、作品脚本与三张素材。
